1. Problemet

Skatteverkets flyttblankett (SKV 7842) kräver 12 fält. Utan automatisering måste en användare manuellt fylla i allt: namn, personnummer, nuvarande adress, ny adress, fastighetsbeteckning, fastighetsägare, telefon, e-post och flyttdatum.

Målet: Med enbart ett personnummer som input, härleda så många fält som möjligt automatiskt — utan betalda API:er, utan organisationsavtal, utan Docker-containrar.

2. Lösningen: en kedja i fyra steg

1
Biluppgifter.se — PNR till namn + adress
Playwright/curl_cffi scrape · ~5 sek
namn gatuadress postnr stad lgh-nr ålder
2
Eniro personsök — telefon + fastighetsbeteckning (nuv.)
Playwright headless · JSON-LD + synlig HTML · ~15 sek
telefon postnr gata fastighetsbeteckning födelsedatum
3
Användaren anger ny adress + datum
3 manuella fält · PAP API fyller i postort automatiskt
ny gatuadress nytt postnr flyttdatum
4
Eniro kartvy — fastighetsägare + beteckning (ny adress)
Två Playwright-sessioner: Företag-flik + Person-flik · ~20 sek
fastighetsbeteckning fastighetsägare (BRF/HSB)

5. Varför det inte finns en enklare väg

Alternativ som inte fungerar

AlternativProblemet
SPAR
(Statens personadressregister)		 Juridiskt avtal krävs med Skatteverket. Kräver organisationsnummer, syftesredogörelse och granskning. Inte tillgängligt för en startup eller privatperson.
Lantmäteriet / VALID API Fastighetsbeteckning direkt från kartan, men kräver licens + avgift per uppslag (ca 0,50–2 kr/sökning). Kräver avtal.
Ratsit / Merinfo API API-paket 500–5 000 kr/mån för begränsad volym. Ger inte fastighetsbeteckning.
allabrf.se Kräver inloggning, ingen öppen API. Reverse-engineering av HAR-filer nödvändigt.
En enda källa Ingen enskild källa har alla 12 fält. Biluppgifter saknar telefon + fastighet, Eniro saknar PNR-koppling, PAP saknar allt utom geografi.

Vad kedjan gör bättre

Noll kostnad. Alla datakällor — Biluppgifter.se, Eniro (personsök + kartvy) och PAP API — är öppna och gratis. Ingen API-nyckel krävs för kärnfunktionaliteten.
En enda input. Personnumret räcker. Allt annat härleds: PNR → namn → personsida → telefon + nuv. fastighet → ny adress → kartvy → BRF + beteckning
Smart fallback-kedja. Om en källa misslyckas (t.ex. personen saknas i Eniro) fortsätter flödet och frågar användaren om de saknade fälten. Inget steg är fatalt.

9. Slutsats

Denna kedja är troligen det enklaste flödet för att automatiskt fylla i Skatteverkets flyttblankett, av tre skäl:

  1. Ingen annan gratiskälla ger PNR → namn + adress. Biluppgifter.se är den enda öppna tjänsten som tar ett fullständigt personnummer och returnerar namn + gatuadress, utan inloggning eller API-nyckel.
  2. Ingen annan gratiskälla ger fastighetsbeteckning per adress. Lantmäteriet kräver licens. Eniros kartvy med Person-fliken är det enda sättet att nå denna data utan kostnad — via en omväg genom en boendes personsida.
  3. Ingen annan gratiskälla ger fastighetsägare per adress. BRF-namn dyker upp i Eniros Företag-flik, men inte i någon REST-API. Tier-systemet (BRF → HSB → generiskt) ger en tillförlitlig gissning.

De 3 fält som förblir manuella — ny gatuadress, flyttdatum och e-post — kan per definition inte härledas automatiskt: adressen är ny, datumet är ett beslut, och e-post finns inte i offentliga register.
